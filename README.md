# Share

ログインなしで、端末どうしでファイルを送れるWebアプリです。
ファイルはサーバーに保存されず、WebRTCで端末から端末へ直接届きます。

## 使い方

### コードで送る
1. 「コードで送る」からファイルを選んで「コードを作る」
2. 表示された6桁コード（またはリンク・QR）を相手に伝える
3. 相手がコードを入れると、直接転送が始まります
   - 送る側は、相手が受け取るまでページを開いたままにしてください

### 部屋で送る
1. 「部屋で送る」から部屋を作る（または4桁コードで入る）
2. 部屋にいる端末の一覧から、送りたい相手の「送る」をタップ
3. ファイルを選ぶと、その相手へ直接送られます

## しくみ
- 接続の仲介には PeerJS Cloud（公開シグナリング）を使用
- ファイル本体は WebRTC のデータチャネルで端末間を直接移動します
- アイコンは Material Symbols（Google Fonts）を使用
